# TikTok Shop Authentication

## Use When

- You need OAuth setup, callback handling, token exchange, or refresh logic.
- You need to generate or validate request signatures.

## Endpoints & Payloads (v202309)

### 1. Get Access Token
`GET /api/v2/token/get`
Exchanges an authorization code for an access token.

**Request Query Parameters:**
- `app_key` (string): The App Key
- `app_secret` (string): The App Secret
- `auth_code` (string): Authorization code from the callback URL
- `grant_type` (string): Must be `authorized_code`

**Response Example:**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "access_token": "act.123...",
    "access_token_expire_in": 1209600,
    "refresh_token": "rft.456...",
    "refresh_token_expire_in": 1209600,
    "seller_name": "Test Store",
    "seller_base_region": "UK"
  }
}
```

### 2. Signature Generation (HMAC-SHA256)
All API requests (except OAuth) require a `sign` parameter in the query string.
The signature string is generated by concatenating:
1. `app_key`
2. Input query string parameters (excluding `sign`, `access_token`), sorted alphanumerically.
3. The body of the HTTP request.
Then signed via HMAC-SHA256 using the `app_secret`.

## Essentials

- Use TikTok Shop Open Platform v202309.
- Treat OAuth and HMAC signing as mandatory for authenticated requests.
- Keep signature construction consistent with the platform rules and your local connection service.
