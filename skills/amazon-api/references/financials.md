# Amazon SP-API Financials (Mexico)

## Use When

- Implementing financial reconciliation for Amazon Mexico sales.
- Retrieving settlement reports and fee breakdowns.
- Analyzing order-level profitability (commissions, shipping, taxes, refunds).

## API References (SP-API)

**Regional Endpoint:** `https://sellingpartnerapi-na.amazon.com`
**Mexico Marketplace ID:** `A1AM78C64UM0Y8`

## Two Approaches to Financial Data

Amazon provides two distinct methods for accessing financial data:

| Method | API | Format | Best For |
|---|---|---|---|
| **Finances API** | `/finances/v0/` | JSON (real-time) | Auditing specific orders, real-time dashboards |
| **Settlement Reports** | `/reports/2021-06-30/` | Tab-delimited flat file | Periodic accounting, bulk reconciliation |

---

## 1. Finances API (v0) — Real-Time Event Data

### List Financial Event Groups (Settlement Periods)

`GET /finances/v0/financialEventGroups`

Returns a list of financial event groups (settlement periods), each with a `FinancialEventGroupId`.

**Query Parameters:**
| Parameter | Description |
|---|---|
| `FinancialEventGroupStartedAfter` | ISO 8601 datetime |
| `FinancialEventGroupStartedBefore` | ISO 8601 datetime |
| `MaxResultsPerPage` | Max 100 |

### List Financial Events by Group

`GET /finances/v0/financialEventGroups/{eventGroupId}/financialEvents`

Drills into a specific settlement period to get all transactions: sales, refunds, fees, adjustments.

### List Financial Events by Order

`GET /finances/v0/financialEvents?PostedAfter=...&PostedBefore=...`

Or for a specific order:
`GET /finances/v0/orders/{orderId}/financialEvents`

**Response Fragment:**

## 2. Settlement Reports (Reports API) — Bulk Reconciliation

### Request a Settlement Report

Settlement reports are automatically generated by Amazon (typically every 14 days). You do not create them; you find them by querying generated reports.

`GET /reports/2021-06-30/reports?reportTypes=GET_V2_SETTLEMENT_REPORT_DATA_FLAT_FILE_V2`

### Request an On-Demand Report

For other report types (like returns or inventory), you must request Amazon to generate them.

`POST /reports/2021-06-30/reports`

**Request Body:**
```json
{
  "reportType": "GET_FLAT_FILE_RETURNS_DATA_BY_RETURN_DATE",
  "marketplaceIds": ["A1AM78C64UM0Y8"],
  "dataStartTime": "2026-04-01T00:00:00Z",
  "dataEndTime": "2026-04-30T23:59:59Z"
}
```

This returns a `reportId`. You then poll `GET /reports/2021-06-30/reports/{reportId}` until the `processingStatus` is `DONE`.

### Common Report Types

| Report Type | Description |
|---|---|
| `GET_V2_SETTLEMENT_REPORT_DATA_FLAT_FILE_V2` | Bi-weekly settlement reconciliation |
| `GET_FLAT_FILE_RETURNS_DATA_BY_RETURN_DATE` | MFN (Seller Fulfilled) returns report |
| `GET_FBA_MYI_UNSUPPRESSED_INVENTORY_DATA` | FBA inventory levels |
| `GET_MERCHANT_LISTINGS_ALL_DATA` | Full catalog export |

### Download the Report

1. Find the `reportId` from the list above.
2. Call `GET /reports/2021-06-30/reports/{reportId}` to get the `reportDocumentId`.
3. Call `GET /reports/2021-06-30/documents/{reportDocumentId}` to get a presigned download URL.
4. Download and parse the tab-delimited file.

**Report Columns Include:**
- `settlement-id`, `settlement-start-date`, `settlement-end-date`
- `order-id`, `sku`, `quantity-purchased`
- `product-sales`, `product-sales-tax`
- `shipping-credits`, `shipping-credits-tax`
- `commission`, `fba-fees`
- `other-transaction-fees`, `total`

## Fee Types Reference

| Fee Type | Description |
|---|---|
| `Commission` | Amazon referral fee (percentage of sale) |
| `FBAFees` | Fulfillment by Amazon fees (pick, pack, ship) |
| `VariableClosingFee` | Applicable to media categories |
| `ShippingHB` | Handling and shipping charges |
| `GiftWrap` | Gift wrapping fee |

## Prerequisites

- Your SP-API developer profile must be approved for the **Finance and Accounting** role.
- A valid LWA refresh token authorized by the seller is required.

## Local Repo Anchors

- `app/Marketplaces/Services/Finance/AmazonFinanceService.php`

## Notes

- Use the Finances API for real-time order-level auditing and the Settlement Reports for periodic bulk accounting.
- All amounts for Mexico are in `MXN`.
- Fees are returned as **negative** amounts in the response.
- Pagination uses `NextToken` — keep calling until it is null.
